# حول مجلد الكيانات

يحتوي هذا المجلد على توثيق كيانات النظام وتعريفاتها. خُصص مجلد مستقل لكل كيان، ويضم عادةً:

- ملفاً بصيغة `SQL` يوضح تعريف الكيان في قاعدة البيانات.
- ملفاً بصيغة `MD` يشرح الغرض من الكيان وحقوله ومفاتيحه وقيوده وعلاقاته بالكيانات الأخرى.

عند تعديل تعريف كيان، يُرجى تحديث توثيقه المقابل للحفاظ على تطابق الشرح مع بنية قاعدة البيانات.
